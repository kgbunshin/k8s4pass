## Statement

In namespace `{{ns}}` the deployment `web` already exists (image `busybox:1.36`).

1. Create the ConfigMap `web-config` with key `APP_MODE` and value `{{mode}}`.
2. Create the Secret `web-secret` with key `DB_PASSWORD` and value `{{password}}`.
3. Make the deployment `web` consume both as environment variables.

## Setup

```bash
kubectl create namespace {{ns}}
kubectl -n {{ns}} create deployment web --image=busybox:1.36 -- sleep 3600
```

## Check

```
1|ConfigMap web-config with APP_MODE={{mode}}|[ "$(kubectl -n {{ns}} get cm web-config -o jsonpath='{.data.APP_MODE}')" = "{{mode}}" ]
1|Secret web-secret with DB_PASSWORD={{password}}|[ "$(kubectl -n {{ns}} get secret web-secret -o jsonpath='{.data.DB_PASSWORD}' | base64 -d)" = "{{password}}" ]
2|Deployment web references web-config and web-secret|y=$(kubectl -n {{ns}} get deploy web -o yaml); grep -q web-config <<<"$y" && grep -q web-secret <<<"$y"
2|Pod of web receives APP_MODE and DB_PASSWORD|kubectl -n {{ns}} rollout status deploy/web --timeout=60s >/dev/null && [ "$(kubectl -n {{ns}} exec deploy/web -- printenv APP_MODE DB_PASSWORD | tr '\n' ' ')" = "{{mode}} {{password}} " ]
```

## Solution: imperative

```bash
kubectl -n {{ns}} create configmap web-config --from-literal=APP_MODE={{mode}}
kubectl -n {{ns}} create secret generic web-secret --from-literal=DB_PASSWORD={{password}}
kubectl -n {{ns}} set env deployment/web --from=configmap/web-config
kubectl -n {{ns}} set env deployment/web --from=secret/web-secret
```

## Solution: declarative

```bash
kubectl apply -f - <<EOF
apiVersion: v1
kind: ConfigMap
metadata: { name: web-config, namespace: {{ns}} }
data: { APP_MODE: "{{mode}}" }
---
apiVersion: v1
kind: Secret
metadata: { name: web-secret, namespace: {{ns}} }
stringData: { DB_PASSWORD: "{{password}}" }
---
apiVersion: apps/v1
kind: Deployment
metadata: { name: web, namespace: {{ns}} }
spec:
  replicas: 1
  selector: { matchLabels: { app: web } }
  template:
    metadata: { labels: { app: web } }
    spec:
      containers:
        - name: busybox
          image: busybox:1.36
          command: ["sleep", "3600"]
          envFrom:
            - configMapRef: { name: web-config }
            - secretRef: { name: web-secret }
EOF
```
