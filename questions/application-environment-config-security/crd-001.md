## Statement

Create a CustomResourceDefinition named `backups.{{group}}` for the kind `Backup` (plural `backups`, singular `backup`).

- It must be **namespaced** and have a single version `v1`, which is served and is the storage version.
- Its schema must define `spec.schedule` (string) and `spec.retention` (integer).

Then, in namespace `{{ns}}`, create a `Backup` named `nightly` with schedule `{{schedule}}` and retention `{{retention}}`.

## Setup

```bash
kubectl delete crd backups.{{group}} --ignore-not-found
kubectl create namespace {{ns}}
```

## Check

```
1|CRD backups.{{group}} is Established|[ "$(kubectl get crd backups.{{group}} -o jsonpath='{.status.conditions[?(@.type=="Established")].status}')" = "True" ]
1|kind Backup, plural backups, singular backup|[ "$(kubectl get crd backups.{{group}} -o jsonpath='{.spec.names.kind} {.spec.names.plural} {.spec.names.singular}')" = "Backup backups backup" ]
1|CRD is namespaced|[ "$(kubectl get crd backups.{{group}} -o jsonpath='{.spec.scope}')" = "Namespaced" ]
1|single version v1, served and storage|[ "$(kubectl get crd backups.{{group}} -o jsonpath='{.spec.versions[*].name} {.spec.versions[0].served} {.spec.versions[0].storage}')" = "v1 true true" ]
2|schema: spec.schedule is a string and spec.retention an integer|[ "$(kubectl get crd backups.{{group}} -o jsonpath='{.spec.versions[0].schema.openAPIV3Schema.properties.spec.properties.schedule.type} {.spec.versions[0].schema.openAPIV3Schema.properties.spec.properties.retention.type}')" = "string integer" ]
1|Backup nightly has schedule {{schedule}}|[ "$(kubectl -n {{ns}} get backups.{{group}} nightly -o jsonpath='{.spec.schedule}')" = "{{schedule}}" ]
1|Backup nightly has retention {{retention}}|[ "$(kubectl -n {{ns}} get backups.{{group}} nightly -o jsonpath='{.spec.retention}')" = "{{retention}}" ]
1|the schema is enforced (a non-integer retention is rejected)|kubectl get crd backups.{{group}} >/dev/null 2>&1 && ! printf 'apiVersion: {{group}}/v1\nkind: Backup\nmetadata:\n  name: invalid\nspec:\n  retention: abc\n' | kubectl -n {{ns}} apply --dry-run=server -f - >/dev/null 2>&1
```

## Solution: apply

```bash
kubectl apply -f - <<EOF
apiVersion: apiextensions.k8s.io/v1
kind: CustomResourceDefinition
metadata:
  name: backups.{{group}}
spec:
  group: {{group}}
  scope: Namespaced
  names:
    plural: backups
    singular: backup
    kind: Backup
  versions:
    - name: v1
      served: true
      storage: true
      schema:
        openAPIV3Schema:
          type: object
          properties:
            spec:
              type: object
              properties:
                schedule:
                  type: string
                retention:
                  type: integer
EOF
kubectl wait --for=condition=established crd/backups.{{group}} --timeout=60s
kubectl apply -f - <<EOF
apiVersion: {{group}}/v1
kind: Backup
metadata:
  name: nightly
  namespace: {{ns}}
spec:
  schedule: "{{schedule}}"
  retention: {{retention}}
EOF
```

## Solution: create with a stricter schema

```bash
cat > /tmp/backup-crd-{{ns}}.yaml <<EOF
apiVersion: apiextensions.k8s.io/v1
kind: CustomResourceDefinition
metadata:
  name: backups.{{group}}
spec:
  group: {{group}}
  scope: Namespaced
  names:
    plural: backups
    singular: backup
    kind: Backup
    shortNames: [bk]
  versions:
    - name: v1
      served: true
      storage: true
      schema:
        openAPIV3Schema:
          type: object
          properties:
            spec:
              type: object
              required: [schedule]
              properties:
                schedule:
                  type: string
                retention:
                  type: integer
                  minimum: 1
EOF
kubectl create -f /tmp/backup-crd-{{ns}}.yaml
kubectl wait --for=condition=established crd/backups.{{group}} --timeout=60s
cat > /tmp/backup-{{ns}}.yaml <<EOF
apiVersion: {{group}}/v1
kind: Backup
metadata:
  name: nightly
spec:
  schedule: "{{schedule}}"
  retention: {{retention}}
EOF
kubectl -n {{ns}} create -f /tmp/backup-{{ns}}.yaml
rm -f /tmp/backup-crd-{{ns}}.yaml /tmp/backup-{{ns}}.yaml
```
