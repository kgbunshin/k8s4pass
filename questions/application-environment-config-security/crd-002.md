## Statement

Another team installed a custom resource of kind `Widget` in this cluster. You do not know its API group or its required fields, so discover them (for example with `kubectl api-resources`, `kubectl get crd` and `kubectl explain`).

1. In namespace `{{ns}}`, create a `Widget` named `{{name}}` with size `{{size}}` and color `{{color}}`.
2. Label it `tier={{tier}}`.

Do not modify the CRD.

## Setup

```bash
kubectl delete crd widgets.{{group}} --ignore-not-found
kubectl create namespace {{ns}}
kubectl apply -f - <<EOF
apiVersion: apiextensions.k8s.io/v1
kind: CustomResourceDefinition
metadata:
  name: widgets.{{group}}
spec:
  group: {{group}}
  scope: Namespaced
  names:
    plural: widgets
    singular: widget
    kind: Widget
    shortNames: [wdg]
  versions:
    - name: v1
      served: true
      storage: true
      schema:
        openAPIV3Schema:
          type: object
          properties:
            spec:
              type: object
              required: [size, color]
              properties:
                size:
                  type: string
                  enum: [small, medium, large]
                color:
                  type: string
EOF
kubectl wait --for=condition=established crd/widgets.{{group}} --timeout=60s
```

## Check

```
2|Widget {{name}} exists and the CRD is untouched|kubectl -n {{ns}} get widgets.{{group}} {{name}} >/dev/null && [ "$(kubectl get crd widgets.{{group}} -o jsonpath='{.spec.versions[0].schema.openAPIV3Schema.properties.spec.required[*]}')" = "size color" ]
1|Widget {{name}} has size {{size}}|[ "$(kubectl -n {{ns}} get widgets.{{group}} {{name}} -o jsonpath='{.spec.size}')" = "{{size}}" ]
1|Widget {{name}} has color {{color}}|[ "$(kubectl -n {{ns}} get widgets.{{group}} {{name}} -o jsonpath='{.spec.color}')" = "{{color}}" ]
1|Widget {{name}} is labeled tier={{tier}}|[ "$(kubectl -n {{ns}} get widgets.{{group}} {{name}} -o jsonpath='{.metadata.labels.tier}')" = "{{tier}}" ]
```

## Solution: discover, then apply and label

```bash
kubectl api-resources --api-group={{group}}
kubectl get crd widgets.{{group}} -o jsonpath='{.spec.versions[0].schema.openAPIV3Schema.properties.spec}'
kubectl apply -f - <<EOF
apiVersion: {{group}}/v1
kind: Widget
metadata:
  name: {{name}}
  namespace: {{ns}}
spec:
  size: {{size}}
  color: {{color}}
EOF
kubectl -n {{ns}} label widgets.{{group}} {{name}} tier={{tier}}
```

## Solution: single manifest with the label

```bash
kubectl create -f - <<EOF
apiVersion: {{group}}/v1
kind: Widget
metadata:
  name: {{name}}
  namespace: {{ns}}
  labels:
    tier: {{tier}}
spec:
  color: {{color}}
  size: {{size}}
EOF
```
