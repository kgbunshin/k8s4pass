## Statement

In namespace `{{ns}}`:

1. Create a PersistentVolumeClaim `data-pvc` requesting `{{size}}` of storage with access mode `ReadWriteOnce` (use the default StorageClass).
2. Create a Pod `{{pod}}` (image `busybox:1.36`, command `sleep 3600`) that mounts the claim at `/data`.

The claim must be `Bound` and the Pod `Ready`.

## Setup

```bash
kubectl create namespace {{ns}}
```

## Check

```
1|PVC data-pvc requests {{size}}|[ "$(kubectl -n {{ns}} get pvc data-pvc -o jsonpath='{.spec.resources.requests.storage}')" = "{{size}}" ]
1|access mode is ReadWriteOnce|[ "$(kubectl -n {{ns}} get pvc data-pvc -o jsonpath='{.spec.accessModes[*]}')" = "ReadWriteOnce" ]
1|PVC is Bound|[ "$(kubectl -n {{ns}} get pvc data-pvc -o jsonpath='{.status.phase}')" = "Bound" ]
1|Pod {{pod}} uses the claim data-pvc|[ "$(kubectl -n {{ns}} get pod {{pod}} -o jsonpath='{.spec.volumes[*].persistentVolumeClaim.claimName}')" = "data-pvc" ]
1|the claim is mounted at /data|kubectl -n {{ns}} get pod {{pod}} -o jsonpath='{.spec.containers[0].volumeMounts[*].mountPath}' | grep -qw /data
1|Pod {{pod}} is Ready|kubectl -n {{ns}} wait --for=condition=Ready pod/{{pod}} --timeout=60s
```

## Solution: one manifest

```bash
kubectl apply -f - <<EOF
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
  namespace: {{ns}}
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: {{size}}
---
apiVersion: v1
kind: Pod
metadata:
  name: {{pod}}
  namespace: {{ns}}
spec:
  containers:
    - name: app
      image: busybox:1.36
      command: ["sleep", "3600"]
      volumeMounts:
        - name: data
          mountPath: /data
  volumes:
    - name: data
      persistentVolumeClaim:
        claimName: data-pvc
EOF
```

## Solution: claim first, then pod

```bash
kubectl -n {{ns}} apply -f - <<EOF
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: {{size}}
EOF
kubectl -n {{ns}} apply -f - <<EOF
apiVersion: v1
kind: Pod
metadata:
  name: {{pod}}
spec:
  volumes:
    - name: storage
      persistentVolumeClaim:
        claimName: data-pvc
  containers:
    - name: main
      image: busybox:1.36
      args: ["sleep", "3600"]
      volumeMounts:
        - {name: storage, mountPath: /data}
EOF
```
