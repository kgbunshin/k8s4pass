## Statement

In namespace `{{ns}}`, create a Job named `{{name}}` that runs `echo done` in a `busybox:1.36` container, with:

- `completions` set to {{completions}};
- `parallelism` set to 2;
- `backoffLimit` set to 2;
- `restartPolicy` set to `Never`.

Wait until the Job has completed.

## Setup

```bash
kubectl create namespace {{ns}}
```

## Check

```
1|Job {{name}} has completions {{completions}}|[ "$(kubectl -n {{ns}} get job {{name}} -o jsonpath='{.spec.completions}')" = "{{completions}}" ]
1|parallelism is 2|[ "$(kubectl -n {{ns}} get job {{name}} -o jsonpath='{.spec.parallelism}')" = "2" ]
1|backoffLimit is 2|[ "$(kubectl -n {{ns}} get job {{name}} -o jsonpath='{.spec.backoffLimit}')" = "2" ]
1|restartPolicy is Never|[ "$(kubectl -n {{ns}} get job {{name}} -o jsonpath='{.spec.template.spec.restartPolicy}')" = "Never" ]
2|all {{completions}} completions succeeded|[ "$(kubectl -n {{ns}} get job {{name}} -o jsonpath='{.status.succeeded}')" = "{{completions}}" ]
```

## Solution: manifest

```bash
kubectl apply -f - <<EOF
apiVersion: batch/v1
kind: Job
metadata:
  name: {{name}}
  namespace: {{ns}}
spec:
  completions: {{completions}}
  parallelism: 2
  backoffLimit: 2
  template:
    spec:
      restartPolicy: Never
      containers:
        - name: {{name}}
          image: busybox:1.36
          command: ["echo", "done"]
EOF
kubectl -n {{ns}} wait --for=condition=complete job/{{name}} --timeout=90s
```

## Solution: dry-run and sed

```bash
kubectl -n {{ns}} create job {{name}} --image=busybox:1.36 --dry-run=client -o yaml -- echo done \
  | sed '0,/^spec:/s//spec:\n  completions: {{completions}}\n  parallelism: 2\n  backoffLimit: 2/' \
  | kubectl apply -f -
kubectl -n {{ns}} wait --for=condition=complete job/{{name}} --timeout=90s
```
